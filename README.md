# LUCAHDMUSICA

Archivio musicale del laboratorio **LUCAHD**.

Repository per testi, strutture armoniche, prompt di produzione, note di sessione e materiali di lavoro delle composizioni originali. Non è un catalogo di audio binari: i file pesanti (WAV, stem, master) restano fuori da Git e si collegano da qui.

## Struttura

```text
LUCAHDMUSICA/
├── lyrics/          testi e schede brano
├── prompts/         prompt di generazione e direzione artistica
├── sessions/        note di sessione, arrangement, mix
└── README.md
```

## Convenzione dei brani

Ogni pezzo ha una scheda in `lyrics/` con:

- titolo e anno
- tema e registro (lirico, pop, narrativo, sperimentale)
- struttura (strofa, ritornello, ponte)
- testo
- note di interpretazione e di produzione

I file audio non vanno committati. In `sessions/` si annota solo il percorso esterno o il link di rilascio.

## Licenza dei testi

I testi originali restano di proprietà dell’autore salvo diversa indicazione nel singolo file.
